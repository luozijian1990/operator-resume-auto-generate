# 虚构测试简历

以下内容仅用于测试，不代表真实用户经历。

## 项目一：门店报表服务发布改造

技术栈：Docker Compose、Jenkins、Harbor、Redis、Kafka、Trivy。

背景：门店报表服务原来逐店人工部署，存在配置不一致、失败后恢复慢的问题。店员每日营业前查看报表，发布窗口需要与门店确认。

个人职责：参与改造，负责 Compose 配置整理与发布后验证。使用 Jenkins 获取 Harbor 中指定镜像，发布清单记录镜像摘要和配置版本；试点门店通过验证后再扩围。发布前备份配置，镜像扫描未通过时停止发布。异常时恢复上一版镜像及配置，核对进程、接口和报表最新时间；方案设计由平台同事负责。

成果：建立门店发布清单和回退检查表，店员确认报表时间正确后关闭发布工单；未统计耗时改善比例。
