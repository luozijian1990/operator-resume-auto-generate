# 最小行为验证

`evals.json` 包含三个虚构案例：有具体行动但成果口径不足、本人职责待核实且提供跨方向参考、仅有一句经历。没有使用真实候选人资料。

2026-11-03：分别执行使用本 Skill 和不加载 Skill 的三例，每组 11 项检查均通过；检查包括原文依据、非数字结果、职责边界、参考与本人事实隔离，以及不要求 JD、不自动改写。执行者自评后复核了 Skill 组的三份报告。

这组检查用于发现边界回归，不证明 Skill 相对基线质量更高，也不代表已覆盖完整简历、图片/OCR、报告文件写入或实际求职效果。测试中发现“交由同事验收”不能当作“验收通过”，已修正检查措辞和公共示例。

重跑时逐个执行 `prompt`，按 `assertions` 检查输出；输出保留在临时目录，公共仓库只维护案例与检查依据。需要人工比较具体措辞和优先级时，可使用 skill-creator 的报告浏览器。
